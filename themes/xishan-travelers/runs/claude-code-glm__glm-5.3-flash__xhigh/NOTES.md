# 溪山行旅 · 水墨动画

## 做了什么

以北宋范宽《溪山行旅图》的构图与笔意为底本，**全程用代码重新画**了一幅竖幅绢本水墨
（未使用任何参考图、贴图或现成模型），并让它动起来，自动演出一段四幕小故事，播完循环。

画面要素均按原画布局程序化生成：

- 顶天立地的主峰（雨点皴、豆瓣皴密点，皴的疏密由程序生成的山体影调图驱动，浓处密、亮处疏）
- 右侧山缝中一道三叠细瀑，瀑脚溅雾，水势有明暗流动
- 山腰云断：一条烘焙的静雾带 + 两层缓慢对飘的雾 sprite
- 中景右侧林台，墨叶成林，梵宇殿阁半藏林间；左肩岩台与左崖叠瀑
- 山脚溪床、水纹、驮道沙路、前景大石（勾勒收边、枯笔飞白）
- 绢本做旧：底色不匀、经纬织纹、霉斑旧渍、纤维、四边包浆沉暗、角落残印

四幕故事（全片约 48 秒，纯时间函数驱动，到尾自动循环）：

1. **晨雾**（0–11s）：山脚浓雾，雾气缓缓散开，主峰渐露，瀑布开始流动
2. **行旅**（11–23s）：一队商旅——引路人 + 四头负货驮骡——自右侧林边走出，沿溪边小路向左行进
3. **钟声**（23–34s）：林中寺院鸣钟（声波成环荡开），群鸟自树梢惊起；殿后人停步仰观山色，再急步追上队伍
4. **入山**（34–48s）：驮队走入左侧山路，渐隐不见；雾气重新合拢，右下角叶隙间浮现「范宽」小字落款与一方向印

每幕配竖排字幕（幕次红字 + 两行句子），在画内左侧留云处淡入淡出。

## 用了哪些技术

- 原生 **Canvas 2D**，无框架、无外部依赖、无网络请求（字体用系统宋体/衬线栈）
- 画法工具（`ink.js`）：可复现的种子随机、一维值噪声、勾勒（毛边折线）、枯笔飞白（平行断续细线）、
  湿笔墨团（径向渐变叠加）、雨点皴（读取影调图的像素，按明暗决定点的大小疏密）
- 画面一次性渲染到离屏画布（1440×2880），之后每帧只做合成：底画 + 雾层 + 瀑布流动 + 驮队 +
  飞鸟 + 钟声波环 + 落款 + 绢纹，桌面浏览器实测 120fps
- 动画全部是时间 t 的纯函数，任意时刻可精确复现（`?t=秒数` 可定位，`&freeze=1` 可暂停）
- 自适应：画面按窗口等比完整显示，手机竖屏占满宽度；字幕字号随视口缩放

## 怎么操作

- **无需任何操作**：打开即自动播放并循环
- 桌面 / 手机 / 触屏均可；页面不响应输入（自动播放的"画"）
- 调试参数（可选）：`?t=27.5` 从第 27.5 秒开始，`&freeze=1` 定格

## 已知问题

- 落款「范宽」与印章文字依赖系统字体（宋体/衬线），不同平台笔画样式略有差异
- 老旧设备上首次生成画面（数千次皴点）可能需要 1–2 秒，期间显示绢底色
