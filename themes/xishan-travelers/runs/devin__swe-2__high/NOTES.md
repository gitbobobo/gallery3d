# 溪山行旅图 · 动态水墨

## 做了什么

用代码把范宽《溪山行旅图》重新画成一幅水墨立轴，并演一个四幕循环小故事。

画面构图照原画：顶天立地的主峰占上半幅，右侧山缝垂一线细瀑，山腰一条云带把山脚埋进雾里，中景是成片密林和林隙间露出的两重檐寺院，山脚有溪水、滩石和一条沿溪山径，最前是皴擦巨石。绢本做了旧底色、经纬丝纹、折痕、水渍霉点和朱色残印；山石用雨点皴、点苔、分面皴擦和多遍积墨；全部图形由 Canvas 2D 程序化生成，没有用任何图片素材。

四幕自动循环（约 46 秒一轮）：

1. 晨雾：山脚浓雾渐散，主峰显露，瀑布开始流动
2. 行旅：三名商旅赶四头驮骡从右出林，沿溪径向左
3. 钟声：寺钟响（空气涟漪三圈），树梢惊起鸟群；押队的人驻足仰头望山，再快步追上队伍
4. 入山：驮队没入左侧山路渐隐，雾气合拢，右下角树叶间浮出"范宽"落款，然后从头循环

## 技术

- 纯 Canvas 2D，无框架、无依赖、无外部资源
- 静态画一次性渲染进 1080×2160 离屏画布（固定随机种子），雾、瀑光、驮队、飞鸟、钟声涟漪、落款为每帧动态层
- 字幕用系统楷体（Kaiti SC / KaiTi 等回退）
- 调试参数：`?t=秒数` 可从时间线任意位置起播

## 操作

不需要任何操作，打开自动播放、自动循环；横竖屏、手机尺寸自适应（画心居中、四周留深色绫边）。

## 已知问题

- 驮骡、人物是几像素级的墨点剪影，近看极简
- 字幕字体依赖系统楷体，无楷体的环境回退为宋体系字体
