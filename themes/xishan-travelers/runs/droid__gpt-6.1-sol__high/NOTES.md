# 溪山行旅

以范宽《溪山行旅图》的构图为参考，用代码重新绘制竖幅水墨山水。主峰、山缝细瀑、山腰云雾、林间寺院、溪边小路和前景巨石均由程序生成，未使用参考照片或外部图像素材。

故事自动播放，80 秒一轮，分为晨雾、行旅、钟声、入山四幕。四头驮骡沿溪行走，钟声时飞鸟起林，最后的行人驻足望山再赶上队伍。结尾人影入山，雾重新合拢，右下树叶间浮现范宽落款。

## 技术

原生 HTML、CSS、JavaScript ES 模块与 Canvas 2D。使用固定随机种子生成绢本纹理、墨染、雨点皴、断笔山石与树叶。静态画层预绘制，动态画层单独更新。声音使用 Web Audio 合成，不依赖网络、后端或音频素材。无构建工具，`dist/` 即静态成品，入口为 `dist/index.html`。

## 操作

- 打开即播放，不需要点击。
- 鼠标点击或触摸右上角可暂停、继续、开关声音。声音默认关闭。
- 点击或触摸四幕名称可跳到该幕。
- 空格键暂停或继续，左右方向键切换章节。
- 页面自动适应全屏、半屏和手机竖屏。系统设置减少动态效果时，取消流水、鸟翼和步态的快速摆动，故事仍会播放。

## 检查

运行 `node tests/story.test.mjs` 可检查四幕时间、四头驮骡、行人驻足与赶路、循环衔接。测试及 JavaScript 语法检查均通过，浏览器未报告运行错误。已预览全屏、半屏、手机竖屏和矮屏布局。

自动无障碍检查未发现违规项，但绢本纹理、渐变背景上的文字对比度仍无法自动判定。
