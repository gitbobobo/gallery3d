# 溪山行旅 · 水墨动画

## 做了什么

用代码把范宽《溪山行旅图》重新画了一遍，再让画动起来，演一段四幕小故事。成品里没有用参考图，画面全部由 Canvas 2D 程序生成。

画面（竖幅，构图照原画）：

- 绢本旧底色：暖褐色底，带边缘氧化暗角、水渍、绢缝、划痕和几枚红印。
- 顶天立地的主峰：浓淡干湿的墨色，密集的竖向雨点皴和飞白，山腰折痕，山顶和山腰的林木团。
- 右侧山缝里一道细瀑布，山腰被云雾隔开。
- 中景：山丘上的树林、松杉和藏在林中的寺院。
- 山脚：溪水、沙路、一道小跌水，最前面是大石头。

故事（自动播放，循环，一轮约 66 秒）：

1. 晨雾：天刚亮，山脚雾气浓。雾散开，主峰露出来，瀑布从上往下流起来。
2. 行旅：商旅领着四头驮骡，从右边树林后面走出来，沿溪边小路向左。
3. 钟声：寺院钟响，光晕一圈圈散开，一群鸟从树梢飞起。队尾的人停下，抬头望山，再快步追上队伍。
4. 入山：驮队走进左边山路，消失在林后。雾重新合拢，画面回到原画的样子，右下角树叶间浮现“范宽”落款和小印。

每幕有一两句字幕。镜头会在第二、三、四幕推近、跟随驮队，最后拉回全景。

## 技术

- 纯原生 HTML + JS + Canvas 2D，没有构建步骤，`dist/` 就是成品。
- 静态画面启动时一次性画到离屏 Canvas：噪声驱动的墨色网格、按流场撒的皴擦笔触、批量合并的笔画、程序生成的树和寺院。画一遍约 0.3 到 1.3 秒。
- 动态部分每帧用矢量绘制：行人、驮骡（步态按走过的路程计算，脚不打滑）、飞鸟、瀑布、钟声光晕、雾、落款。雾用预渲染的软雾贴图，按时间线调整浓度和位置。
- 驮队从“遮挡层”后面走出来和走进去。遮挡层是用同样的种子把右、左两处林子再画一遍得到的。
- 字体：落款、幕名用 Google Fonts 的 Ma Shan Zheng，字幕用 Noto Serif SC（只请求用到的字）。联网失败时退回系统楷体或宋体，其余功能不受影响。

## 怎么操作

不需要操作，打开就自动播放并循环。没有鼠标、键盘或触摸交互。

页面铺满窗口，画幅按 1:2 自适应。窗口够宽时，左侧显示幕名，右侧是进度点，字幕在画下方。手机竖屏下字幕同样在画下方。

调试用：地址后加 `?t=秒数` 可以停在时间线上的某一刻，例如 `?t=35`。

## 已知问题

- 首次打开时，字幕和落款字体需要从 Google Fonts 加载，网络慢时会先用系统字体显示。
- 画面是程序化的仿作，山石皴法和树木是笔触模拟，和原作的细节不同。
- 手机上驮队人物很小，镜头推近后才看得清。
