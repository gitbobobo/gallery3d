# 机械表机芯 · 3D

用 Three.js 在浏览器里实时渲染的一枚正在运转的机械表机芯。

## 做了什么

一个可交互的 3D 机芯，包含题目要求的全部零件，并按真实传动关系联动：

| 零件 | 齿数 / 参数 | 转速（基准 1×） |
| --- | --- | --- |
| 发条盒 | 72 齿 | 9 小时 / 圈 |
| 二轮（中心轮） | 8 齿小齿轮 + 60 齿轮 | 60 分钟 / 圈 |
| 三轮 | 8 齿小齿轮 + 64 齿轮 | 8 分钟 / 圈 |
| 四轮 | 8 齿小齿轮 + 56 齿轮 | 1 分钟 / 圈 |
| 擒纵轮 | 7 齿小齿轮 + 15 齿轮 | 7.5 秒 / 圈 |
| 摆轮 / 游丝 | 1 Hz（2 拍 / 秒） | 来回摆动 |
| 擒纵叉 | — | 每秒翻转 2 次 |

- 每对咬合齿轮各自使用一个模数（齿形大小），齿数比就是转速比。整列总传动比
  `72/8 × 60/8 × 64/8 × 56/7 = 1 : 4320`。
- 咬合相位是算出来的：每对齿轮在连心线上「一个齿对准另一个的齿槽」，并且
  相邻两轮反向旋转、节圆纯滚动，所以运转时齿与槽始终对齐，不会穿模。
- 摆轮以正弦规律摆动，擒纵叉用 `tanh` 做了「啪嗒」式的快速翻转；擒纵轮连续
  转动，每 7.5 秒一圈，配合摆轮的 2 拍 / 秒节拍。
- 场景里有主夹板（日内瓦纹）、宝石轴承、蓝钢螺丝、发条盒内的发条螺旋、游丝
  螺旋和摆轮卡子等细节。

## 用了哪些技术

- **Three.js**（通过 npm 安装并用 Vite 打包，`base: './'`，产物在 `dist/`）。
- 齿轮几何体全部用代码生成：用 `THREE.Shape` 画梯形齿廓 + 辐条镂空，
  再 `ExtrudeGeometry` 挤出并倒角；发条 / 游丝用阿基米德螺线的
  `CatmullRomCurve3` + `TubeGeometry`。
- 材质用 `MeshStandardMaterial` / `MeshPhysicalMaterial`（金属、宝石），
  环境光照来自 `RoomEnvironment`（程序生成，没有外部贴图），ACES 色调映射。
- 交互用 `OrbitControls`（拖动旋转、滚轮 / 双指缩放）+ `Raycaster` 拾取零件。

## 怎么操作

- **鼠标**：按住左键拖动旋转视角；滚轮缩放；点击零件查看名称与作用。
- **触摸屏**：单指拖动旋转；双指捏合缩放；点按零件查看说明。
- **右下角滑块**：调整「时间倍速」（0.5×–40×）。齿轮比是固定的，调倍速只是
  把整套机芯的时间一起加快，方便观察慢速的轮系（例如把发条盒 / 中心轮转起来）。
  默认 4× 时摆轮为 4 Hz，接近真实手表的振动频率。
- 右上角列表也可以直接点选零件；点击空白处或关闭按钮取消选中。

## 已知问题

- 低倍速下发条盒与中心轮转动极慢（这是真实传动比的必然结果），调高「时间倍速」
  可以明显看到它们转动；但此时摆轮会因频率过高而看不清单次摆动。
- 多枚大轮在俯视方向上会互相重叠——这与真实机芯一样（它们处在不同的高度层），
  并非穿模；实际咬合发生在轮与下一级小齿轮之间。
- 擒纵叉与摆轮的冲量钉只是视觉上接近，没有做完整的锁面 / 冲面物理模拟。
