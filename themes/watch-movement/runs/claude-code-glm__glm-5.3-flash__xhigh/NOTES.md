# 机械表机芯 3D 展示

## 做了什么

用 Three.js 按真实结构建模并驱动一台手动上弦机械表机芯（原型为 18000 vph 传统机芯），包含完整的动力—传动—擒纵—调速链条：

- **发条盒**（72 齿，敞开式盒盖可见发条螺线，上方有大钢轮与棘爪）
- **传动轮系**：中心轮（64 齿 / 12 瓣）→ 三轮（60 齿 / 8 瓣）→ 四轮即秒轮（70 齿 / 8 瓣，轴上带指针，每分钟一圈）→ 擒纵轮（15 齿）
- **擒纵机构**：擒纵叉（两枚红宝石进/出瓦、叉头、防误动保险销）与摆轮（游丝、圆盘钉、轮缘调速螺钉、防震器）
- **夹板**：主夹板、条夹板、轮系夹板、摆轮夹板（悬臂式），镶红宝石轴承、蓝钢螺钉，日内瓦条纹贴图

### 传动真实性

- 齿轮全部按模数制生成：节圆半径 = m×齿数/2，中心距 = 两轮节圆半径之和，齿在啮合点真实交错
- 每对齿轮的初始相位用啮合约束方程求解（`I = (φp−ψ)/αp + (φc−ψ−π)/αc ≡ 1/2`），任意时刻都保持正确咬合
- 传动比严格按齿数：条盒 6:1 → 中心轮（1 圈/小时）8:1 → 三轮（1 圈/7.5 分钟）7.5:1 → 四轮（1 圈/分钟）10:1 → 擒纵轮（1 圈/6 秒）
- 擒纵轮按离散拍步进（每拍 12°，带快速释放动画），擒纵叉每拍左右换向，摆轮以 2.5 Hz、±270° 摆动，过零时刻与步进同步；上游轮系全部由同一拍计数按齿数比反推，全轮系同源同步
- 摆轮游丝随摆动有"呼吸"形变

## 用了哪些技术

- Three.js（r169）+ Vite 构建（base `./`，产物全部本地化，无外部网络依赖）
- OrbitControls（拖转 / 滚轮缩放 / 触摸单指旋转、双指捏合缩放）
- 所有几何体（渐开线近似齿形、擒纵轮尖齿、辐板镂空、摆轮、螺线游丝、凸包包络夹板）均由代码程序化生成；日内瓦条纹为 Canvas 程序贴图；无任何外部模型 / 贴图 / HDRI
- PBR 材质 + RoomEnvironment 环境光照 + 单方向光软阴影；右上角"隐藏夹板"可剥开夹板直视轮系

## 怎么操作

- **鼠标**：左键拖动旋转，滚轮缩放，右键平移
- **触摸**：单指旋转，双指捏合缩放
- **点击零件**（画面中或左下角清单）：镜头对焦该零件，右下角显示名称与作用说明；点击空白处或 ✕ 关闭
- **右上角**：暂停/继续；速度 ¼×（慢动作看擒纵）/ 1×（实时）/ 4×；"隐藏夹板"切换桥板显示
- 页面打开即自动运转并缓慢旋转展示，任意交互后停止自动旋转

## 已知问题

- 为透视展示做了简化：发条盒内的发条是装饰性螺线（真实发条圈数更多）、未模拟摆轮游丝末圈曲线与快慢针、轴榫/宝石尺寸做了视觉放大
- 条盒轮转速极慢（约 6 小时/圈），1× 下肉眼几乎察觉不到，可用 4× 配合轮系观察
- 夹板与轮系在个别角度存在视觉穿插（真实机芯各层间距更紧凑，此处为可读性放大了层间距）
