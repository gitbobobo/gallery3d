# 机械表机芯 3D 运转演示 · NOTES

## 做了什么

用 Three.js 做了一枚横放的机械表机芯剖视模型，打开即自动运转：

- **完整传动链**：发条盒（96 齿）→ 中央轮（轴齿 12 / 轮 75）→ 三轮（10 / 70）→ 四轮（10 / 60）→ 擒纵轮（轴齿 8 / 轮 15）→ 擒纵叉 → 摆轮游丝，共 7 个可点击部件加主夹板。
- **真实传动比**：各级减速比 8 / 7.5 / 7 / 7.5，总减速 3150:1。所有齿轮取统一模数，相邻两轮中心距 = 两节圆半径之和，转角满足外啮合方程 `Z1·θ1 + Z2·θ2 = (Z1+Z2)·ψ + const`，齿与齿槽交错咬合不穿插。
- **擒纵仿真**：摆轮 2Hz（14400 vph、摆幅 ±250°）正弦摆动；擒纵叉做方波化急跳（±9°）；擒纵轮平时锁定、每半个摆动周期（每拍）用 easeOut 快速跳进一齿（24°），其余时间静止，有“滴答”指示灯闪烁。轮系由擒纵轮角度**反推**各级转角，所以跳动时整列齿轮严格保持啮合。
- **细节**：发条盒内盘绕发条、四轮轴上带蓝钢秒针、擒纵轮 15 个尖齿、擒纵叉两颗红宝石托钻、摆轮配重螺丝 + 双圆盘冲量宝石 + 呼吸式蓝游丝、红宝石轴承托钻、日内瓦条纹主夹板（Canvas 代码生成）。
- **交互**：拖动旋转、滚轮缩放、右键平移（手机触摸旋转/双指缩放）；点击零件右侧面板显示名称、英文名、齿数、传动比和作用说明，同时零件发金光高亮；顶部有悬浮标注（可开关），底部有暂停/慢放/总览/擒纵特写/速度滑杆（0.1×–60×，默认 1×，60× 可看清发条盒转动）。

## 用了哪些技术

- Three.js r160（npm 本地打包，无 CDN 依赖）+ OrbitControls + RoomEnvironment（代码生成环境反射，无外部 HDRI）
- Vite 5 构建，`base: './'`，产物为纯静态 `dist/`（约 0.5MB）
- 全部几何体程序化生成：渐开线近似直齿（梯形齿廓 + 齿根圆弧 + 侧隙）、擒纵轮尖齿、阿基米德螺旋发条/游丝（TubeGeometry）、挤出桥板
- PBR 金属材质 + ACES 色调映射 + PCF 柔和阴影

## 怎么操作

- 鼠标：左键拖动旋转视角，滚轮缩放，右键拖动平移，单击零件查看说明
- 键盘：无专用快捷键（Tab 可聚焦按钮后回车操作）
- 触摸：单指旋转，双指捏合缩放，点击零件查看说明
- 按钮：⏸ 暂停/运转、🐌 擒纵慢放（0.15×并切特写）、🔭 总览、🧭 擒纵特写、🏷 标注开关、速度滑杆

## 已知问题

- 擒纵叉瓦与擒纵轮齿是“近似对位”而非逐齿碰撞解算，极慢放下偶见宝石与齿尖轻微擦过，不影响整体观感。
- 发条盒按 3150:1 真实减速后在 1× 下几乎不动（约 3 小时一圈，符合真实手表），需把速度拉到 10× 以上才看得出它在转。
- 超大齿数齿轮的倒角较简单，极近距离下齿面不如真实倒角圆润。
