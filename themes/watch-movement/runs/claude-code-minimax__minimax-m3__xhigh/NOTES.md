# 机芯 3D 展示 · 说明

## 做了什么

一个纯网页 3D 演示，模拟一枚正在运转的机械机芯。打开页面后会自动呈现完整的机芯，无需任何点击：

- **发条盒（Barrel）** —— 黄铜大齿轮，外圈六条辐条，对应真实机芯里储存动力的一级
- **传动轮系** —— 中心轮（钢）、三轮（钢）、四轮（钢）共 3 个过桥齿轮，把发条动力一级级放大
- **擒纵轮（Escape Wheel）** —— 金色 15 齿小齿轮，是机芯里转动最快的轮
- **擒纵叉（Pallet Fork）** —— 红色锚形件，两个红宝石叉瓦左右切换，把持续旋转变成脉冲
- **摆轮（Balance Wheel）** —— 钢制带辐条大轮 + 蓝色游丝（5.5 圈扁平螺旋），左右来回摆动
- **底板** —— 程序生成的「日内瓦纹」（Côtes de Genève）圆形黄铜板，边缘排布蓝钢螺丝与红宝石轴承
- **夹板（Bridges）** —— 几块弧形黄铜桥板压住各个齿轮的轴心

齿轮之间按真实的齿数比联动：

```
发条盒 60 牙 ──► 中心轮 36 牙 ──► 三轮 26 牙 ──► 四轮 18 牙 ──► 擒纵轮 15 牙
转速比      1.67×           2.31×           3.33×           4.00×
```

每对齿轮都计算了初始相位偏移（phase offset），让齿对齿的间隙在 t=0 时刚好对齐，转动起来咬合看起来自然。摆轮以约 1.34 Hz 振荡（≈ 9600 bph，常见 4 Hz 机芯的合理范围），擒纵叉跟着摆轮做反向小幅摆动，并把动能脉冲式传给擒纵轮。右下角实时显示每小时的振频（bph）。

## 用了哪些技术

- **Three.js r132.2**（`dist/three.min.js`，≈ 600 KB）—— 核心 3D 引擎，从 jsDelivr CDN 下载后落到本地，离线可跑
- **OrbitControls**（`dist/OrbitControls.js`，r132.2，legacy 版本）—— 鼠标 / 触摸旋转与缩放
- **原生 JavaScript** —— 没有打包工具，没有构建步骤，页面打开即可运行
- **纯过程化几何** —— 所有齿轮、桥板、摆轮、游丝、擒纵叉都由代码生成（`THREE.Shape` + `ExtrudeGeometry`、`CatmullRomCurve3` + `TubeGeometry`），没有任何外部模型
- **过程化贴图** —— 黄铜底板的「日内瓦纹」由 `CanvasTexture` 程序绘制：同心圆弧 + 渐变高光 + 细微噪声；红宝石轴承用 `MeshPhysicalMaterial`（`transmission`/`ior`）模拟玻璃质感
- **PBR + ACESFilmicToneMapping** —— `MeshStandardMaterial` 设置金属度 / 粗糙度，ACES 色调映射让金属反射更自然
- **PCFSoftShadowMap** —— 软阴影，齿轮投影在底板上可见
- **CSS BackdropFilter** —— 信息卡片用半透明 + 模糊玻璃效果
- **Raycaster** —— 点击零件时检测出对应的 mesh，弹出对应的名称、功能、齿数、转速比

## 怎么操作

| 操作 | 桌面端 | 手机端 |
| ---- | ------ | ------ |
| 旋转视角 | 鼠标左键拖动 | 单指拖动 |
| 缩放 | 滚轮 | 双指捏合 |
| 查看零件信息 | 点击零件 | 点击零件（≤350 ms、≤6 px 抖动识别为点击而非拖动） |
| 关闭信息卡 | 点击卡片右上角 × | 点击卡片右上角 × |
| 自动播放 | 打开即开始运行 | 打开即开始运行 |

点击任意齿轮、擒纵叉、摆轮、底板，都会弹出对应卡片，中英文双语显示名称、功能介绍，以及齿数 / 转速比 / 振频等参数。

## 已知问题

- 齿轮齿形是简化的**梯形齿**（近似梯形 + 间隙），不是真正的渐开线齿形，咬合看起来自然但严格意义上只是视觉近似
- 没有真实的擒纵器动力学 —— 摆轮是纯正弦振荡，擒纵轮是匀速转动，二者靠相位对齐形成视觉上的"擒纵"效果，没有模拟实际能量释放/冲击
- 没有发条上链、动力存储指示等功能；底板背面、擒纵调速器（无快慢针）、日历机构等也未做
- 极端缩放距离下，部分小零件（螺丝、宝石）会因为像素化而显得粗糙
- 在非常窄的手机屏幕（< 360 px 宽）下，信息卡可能需要手动滚动查看全部内容
