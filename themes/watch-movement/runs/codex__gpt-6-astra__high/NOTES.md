# Calibre 01 机械表机芯

## 做了什么
用 3D 方式展示一枚正在运转的手动机械表机芯：包含发条盒、中心轮、第三轮、第四轮、擒纵轮、擒纵叉和摆轮。齿轮按 80/10、75/10、80/8 的传动关系连续转动，擒纵叉左右摆动，摆轮按 2.5 Hz 往复摆动。点击零件会在解构面板显示名称、作用和关键参数。

## 技术
- 原生 HTML / CSS / JavaScript
- Three.js（通过 CDN 加载）与 OrbitControls
- 代码生成齿轮、轮辐、桥板、红宝石轴承和摆轮几何体，没有使用外部模型或图片
- 页面是纯静态文件，入口为 `dist/index.html`

## 操作
- 鼠标拖动或触摸拖动：旋转视角
- 滚轮或双指捏合：缩放
- 点击零件：查看名称和作用
- 双击画布或点击“重置视角”：回到默认视角
- 点击“传动原理”查看齿数比，点击底部 0.2× / 1× / 10× 调整时间倍率；空格键暂停，方向键旋转，+ / - 缩放

## 已知问题
- 轮系是教学展示用的近似几何与传动速度模型，未模拟真实机芯中的摩擦、游丝曲线和宝石轴承间隙。
