# CALIBRE 1800 · 机械表机芯 3D 全景解构

## 做了什么

本项目基于现代 WebGL/Three.js 技术，打造了一个完全基于程序化几何算法与真实物理齿轮动力学驱动的 3D 机械腕表机芯可视化交互系统（参考瑞士杠杆式擒纵系统与 18,000 VPH 经典慢摆机芯）。

### 核心实现内容
1. **真实机械结构建模（纯代码生成几何体，无外部 3D 模型/贴图依赖）**：
   - **发条盒总成（Barrel Assembly）**：主发条盒、大钢轮（Ratchet Wheel）、防逆转棘爪（Click & Click Spring）。
   - **传动轮系（Gear Train）**：中心轮（二轮，64T）、过轮（三轮，60T）、秒轮（四轮，70T）以及对应的小齿轮（Pinions），具有准确的渐开线齿廓与镂空五辐臂设计。
   - **瑞士杠杆式擒纵系统（Swiss Lever Escapement）**：15齿鹰嘴状冲口擒纵轮、双臂擒纵叉、合成红宝石进瓦与出瓦（Ruby Pallets）。
   - **调速平衡系统（Oscillating Regulating Organ）**：三臂 Glucydur 摆轮（外缘嵌 16 颗金色配重微调螺丝）、真实游丝卷吸形变动态呼吸效果（12圈阿基米德渐开线游丝）、快慢针调节指示器（Regulator Index）与 Incabloc 避震红宝石碗。
   - **夹板与基板（Bridges & Mainplate）**：主夹板、发条盒夹板（带镂空视窗）、轮系夹板（带轮系透视窗口）、摆轮夹板（Balance Cock）与擒纵叉夹板，表面镶嵌黄金套筒与红宝石轴承，高光烤蓝沉头螺丝紧固。

2. **严谨的动力学与运动学仿真**：
   - **真实传动比啮合传动**：
     - 发条盒 (72T) $\rightarrow$ 中心轮轴翅 (12T) 传动比 6:1
     - 中心轮 (64T) $\rightarrow$ 三轮轴翅 (8T) 传动比 8:1
     - 三轮 (60T) $\rightarrow$ 四轮轴翅 (8T) 传动比 7.5:1
     - 四轮 (70T) $\rightarrow$ 擒纵轮轴翅 (7T) 传动比 10:1
     - 总体四轮到擒纵轮加速传动比高达 600:1。
   - **摆轮简谐振动与游丝呼吸形变**：振频设定为经典 18,000 VPH（2.5 Hz），摆幅 $\pm 270^\circ$；阿基米德螺旋游丝每帧根据瞬时摆角重新计算向心扩张/收缩曲率，模拟真实机械呼吸感。
   - **擒纵步进与锁止释放**：擒纵叉在限位钉之间以冲锁相位精准跳跃切换，擒纵轮与传动轮系遵循脉冲式步进推进。
   - **Web Audio 机械擒纵音效合成**：利用 Web Audio API 动态合成进瓦击打（滴 Tick）与出瓦脱落（嗒 Tock）的高频微瞬态金属共振声，音质逼真且低延迟。

3. **高级高级制表 PBR 材质与程序化纹理**：
   - 程序化生成鱼鳞纹（Perlage / Circular Graining）主夹板底纹。
   - 程序化生成日内瓦波纹（Côtes de Genève）表面平行光栅。
   - 程序化生成太阳放射纹（Sunburst Soleillage）用于发条盒大钢轮。
   - 镜面 45° 倒角抛光边缘（Anglage）、高光烤蓝精钢螺丝（Blued Screws）、天然鸽血红宝石轴承（Corundum Rubies）与 18K 黄金齿轮。
   - 纯代码构建的 PMREM 摄影棚多光源立体反射贴图。

4. **专业级交互系统与解构展示**：
   - **连续爆炸图滑块（Exploded View Slider）**：0%~100% 沿 Z 轴按机械装配层级分层展开，直观展现主夹板、齿轮层、擒纵层与夹板层的空间叠压关系。
   - **夹板透视模式切换**：支持“实体”、“透视”（半透明展示内部轮系）、“隐藏”三种状态。
   - **多预设特写视角**：一键切换“经典 45°”、“俯视”、“擒纵机构特写”、“摆轮特写”、“轮系特写”。
   - **零件拾取与百科卡片**：鼠标悬停显示零件浮动指示，点击任意零件平滑高亮聚焦，弹出包含中英文名、类别、核心规格参数、物理原理与工艺精髓的详细百科卡片。
   - **多档调速与暂停**：支持 0.2x、0.5x 慢动作分解观察与 2.0x 加速，支持一键静音与启停。

## 用了哪些技术

- **核心渲染引擎**：Three.js (r186) 3D WebGL 渲染管线、PBR Physically Based Materials (MeshStandardMaterial / MeshPhysicalMaterial)、PCF 柔和阴影贴图、ACESFilmic 色调映射。
- **构建工具**：Vite 8 构建，ES Module 规范打包，构建产物仅 640KB，完全满足静态相对路径直接部署要求。
- **数学与几何算法**：
  - 基于渐开线齿轮轮廓函数算法化生成各齿轮形状（`THREE.Shape` + `ExtrudeGeometry`）。
  - 阿基米德螺旋线游丝几何体实时点阵变形算法（`BufferGeometry` 顶点更新）。
  - 瑞士杠杆式擒纵轮与锚形擒纵叉多边形路径计算。
- **声音合成**：Web Audio API 自建带通滤波金属冲击瞬态振荡器网络（双相滴答音）。
- **界面架构**：深色高级奢华制表风格 UI、CSS Glassmorphism 拟态玻璃滤镜、响应式布局（完美兼容全屏、半屏及移动端 390x844 竖屏）。

## 怎么操作

### 鼠标操作
- **旋转观察**：按住鼠标左键拖动画布，围绕机芯 360° 自由旋转。
- **平移位置**：按住鼠标右键拖动画布，或按住 `Shift + 鼠标左键` 拖动。
- **缩放视野**：滚动鼠标滚轮放大/缩小机芯细节。
- **零件拾取**：鼠标悬停在零件上查看部件名称提示；单击零件弹出详细规格卡片并高亮指示。
- **关闭卡片**：点击信息卡片右上角 `×` 或点击背景空白区域。
- **特写聚焦**：在信息卡片中点击“镜头特写”或直接使用底部视角预设按钮。

### 触摸操作（手机 / 平板设备）
- **单指滑动**：旋转 3D 视角。
- **双指缩放**：捏合放大/缩小。
- **双指拖动**：平移视角中心。
- **单指轻触**：点击机芯零件唤起详情面板。

### 控制面板功能
- **倍速调节**：顶部右上角可选择 `0.2x`（慢放观察擒纵过程）、`0.5x`、`1.0x`（正常物理频率）或 `2.0x`。
- **音效开关**：点击喇叭图标开启/关闭机械钟表滴答声（首次点击触发音频上下文播放）。
- **暂停 / 播放**：点击暂停/播放按钮可冻结当前机芯运动状态以便微距观察。
- **结构分解滑块**：拖动底部“结构分解”滑块，动态展开各夹板与轮系层。
- **夹板状态**：切换“实体”、“透视”（半透明穿透）、“隐藏”以查看深层齿轮。
- **视角预设**：一键定位“经典45°”、“俯视”、“擒纵”、“摆轮”、“轮系”。
