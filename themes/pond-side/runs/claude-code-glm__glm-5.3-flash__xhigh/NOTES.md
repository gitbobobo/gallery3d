# 池塘一隅

用 3D 展示池塘边的一角：主角是水，一片可以真实互动的小池塘。

## 做了什么

**场景**：不规则的小池塘，岸边有泥土、卵石、四丛芦苇、一棵枝条垂到水面的柳树；一座小木栈桥伸进水里（木桩插在水中）；水面上浮着荷叶和睡莲，浅水下有水草与卵石，六条锦鲤在水下巡游。

**水**是核心，全部实时计算：

- CPU 上的波动方程高度场（224×224 网格，30Hz 步进）：涟漪真实地向外传播（约 1.9m/s）、逐渐衰减、多处涟漪互相叠加；岸边和栈桥木桩是反射边界，波会反弹回来。
- 平面镜像渲染（Reflection RT）：天空、太阳/月亮、柳树、栈桥、芦苇和岸边景物都会倒映在水里，倒影随波纹法线扭曲晃动。
- 折射（Refraction RT，屏幕空间扭曲）：平视时以菲涅尔反射为主，低头看时能看透水面；栈桥木桩、芦苇秆在水面处上下错开，水下的鱼和石头随波纹晃动变形。
- 深度吸收：岸边浅处能看清池底卵石，越往中间越深越暗。
- 焦散：阳光在浅水池底投下随波晃动的光斑（含高度场扰动）。
- 泡沫：波峰白沫 + 岸线水沫。

**互动**（选中道具后点击 / 轻触水面）：

- 涟漪（默认）：点击处激起一圈扩散涟漪。
- 石子：抛物线落水，溅起水花和水滴、一圈大涟漪和回涌的次级涟漪，然后沉到池底；附近的锦鲤会被惊散。
- 纸船：放到水面，随波起伏、被涟漪推动、被风吹着漂，不会穿过岸边和荷叶；最多 6 只。
- 鱼食：撒一小片浮在水面的颗粒，锦鲤会游上来抢食，嘴碰到水面时搅出小涟漪。

**环境**：

- 风（滑杆 0–100）：细波更密更碎、芦苇/柳枝摆动更大、漂浮物漂得更快、柳叶更频繁地飘落水面（无风时偶尔也有）。
- 雨：天色转暗、雨丝斜落、水面密密麻麻的小涟漪和小水花、倒影变模糊。
- 时间（白天 / 黄昏 / 夜晚）：平滑过渡。夜晚有月亮与星星映在水中，萤火虫飞在水面上方，倒影里也看得到它们。
- 页面打开后无需任何操作：微风吹皱水面、锦鲤游动、柳叶偶尔飘落。

## 技术

- Three.js + Vite：已打包进 `dist/`，全部资源本地化，纯静态、无后端、无外链
- 自定义水面 Shader（反射/折射双 RenderTarget + 菲涅尔 + 深度吸收 + 焦散）
- 自研 CPU 波动高度场，DataTexture 上传给 GPU 供水面/焦散/漂浮物共用
- 所有几何体（地形、柳树、芦苇、锦鲤、纸船、荷叶等）与全部贴图（Canvas 程序化生成）均为代码生成，未使用任何外部模型 / 图片 / HDRI
- 相机：OrbitControls（拖动旋转、滚轮/双指缩放），可压低到贴近水面看倒影；相机不会钻入地面或水下
- 适配：铺满视口，桌面 / 半屏 / 手机竖屏（390×844）均可正常操作，触摸单指旋转、双指缩放、轻触放置

## 怎么操作

| 操作 | 效果 |
| --- | --- |
| 拖动（单指滑动） | 旋转视角 |
| 滚轮 / 双指捏合 | 缩放 |
| 点击 / 轻触水面 | 使用当前选中道具 |
| 底部工具栏 | 切换 涟漪 / 石子 / 纸船 / 鱼食 |
| 风 滑杆 | 调节风力（无风 → 强风） |
| 雨 | 开关降雨 |
| 白天 / 黄昏 / 夜晚 | 切换时段 |

## 已知问题

- 折射用屏幕空间扭曲近似：贴着岸边以极低角度看水时，水线附近的画面可能有轻微拉伸。
- 反射为理想平面镜像：漂浮物自身在水线附近的倒影边缘在极端角度下可能有几像素偏差。
- 依赖 WebGL2 与浮点纹理；极旧设备会自动降级（波形法线略微生硬）。
