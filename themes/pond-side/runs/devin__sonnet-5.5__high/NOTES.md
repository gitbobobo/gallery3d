# 池塘一角

一个用 WebGL 实时渲染的 3D 池塘：岸边有泥土、卵石、芦苇和一棵垂枝柳，一座木栈桥伸进水里，水面浮着荷叶和睡莲，水下游着锦鲤。主角是水。

## 做了什么

**水面**
- 波纹用真实的波动方程模拟（384×384 网格，每秒 60 步）：向外扩散、逐渐衰减，几处涟漪相遇会叠加，碰到岸边和栈桥木桩会反射回来。浅水处波速变慢、衰减更快，荷叶和芦苇丛对波有阻尼。
- 风产生的细波是另一层程序生成的波纹，风越大越密越碎，并带有一阵一阵的阵风斑块。下雨时再叠加密集的雨滴波环。
- 倒影：用镜像相机实时渲染天空、柳树、栈桥、芦苇、荷叶和萤火虫，再按波纹法线扭曲、按雨量和风力模糊。
- 折射：水下部分（池底、卵石、水草、锦鲤、木桩、芦苇根部）单独渲染，按水深和波纹扭曲后透过水面看到；水下物体被压扁到视觉深度，所以木桩、芦苇秆在水线处是错开的。
- 菲涅尔：平视以反光为主，俯视能看透；水体按深度吸收红光，越往中间越深越暗。
- 焦散：用波面法线折射阳光，在池底实时累加出光斑，随波纹晃动，被栈桥的影子遮住；只在有阳光时出现。
- 日光/月光/灯笼在水面上有高光闪烁。

**场景**
- 池塘地形用代码生成，岸边渐变为湿泥、沙地和草地；卵石、草叶、水草、芦苇（含蒲棒）、荷叶、睡莲、柳树枝条和柳叶全部是程序生成的几何体，纹理由 Canvas 噪声绘制，没有使用任何外部模型或图片。
- 锦鲤会游走避开浅滩和木桩，会游向鱼食并在水面咬食（搅起涟漪），被石子惊散。
- 柳叶会从枝条上飘落到水面，随风和波纹漂移，几根柳枝尖端会点触水面激起小涟漪。

**互动**
- 点水：在点击处激起一圈涟漪。
- 石子：抛物线落水，溅起水花和水滴，激起大涟漪，附近的鱼被惊散，然后沉到池底。
- 纸船：浮在水面上随波起伏，被涟漪推动、被风吹着漂，遇到岸边、荷叶、木桩和别的船会被挡住，可以放多只（最多 12 只）。
- 鱼食：一撮漂浮的颗粒，随风和波纹漂，锦鲤游来抢食。
- 风力滑块：芦苇、柳枝、草叶摆幅、水面细波、漂浮物漂速和柳叶飘落频率都随之变化。
- 下雨开关：天色变暗，雨丝、雨点水花、密集小涟漪，倒影变模糊。
- 白天 / 黄昏 / 夜晚：光照、天空、水色平滑过渡；夜晚有月亮及其水中倒影，萤火虫在水面上方飞舞（倒影里也有），栈桥上的灯笼点亮。

## 技术

Three.js（r170）+ Vite；波动方程在 CPU 上用 Float32Array 求解，每帧上传一张高度纹理，再由一个 GPU 小通道算出法线；倒影、折射、焦散各自渲染到独立的离屏纹理，水面着色器把它们合成；其余材质通过 `onBeforeCompile` 注入水下吸收、焦散和风摆动。全部使用相对路径，`dist/` 可以放在任意子目录下用静态服务器访问。

## 操作

| | 桌面 | 触摸 |
|---|---|---|
| 旋转镜头 | 鼠标左键拖动 | 单指拖动 |
| 缩放 | 滚轮 | 双指捏合 |
| 放置 / 点水 | 点击水面（拖动不会触发） | 轻触水面 |
| 切换道具 | 底部面板，或键盘 1 点水 / 2 石子 / 3 纸船 / 4 鱼食 | 底部面板 |
| 下雨 | 面板开关，或按 R | 面板开关 |
| 风力、时间 | 面板滑块和按钮 | 面板滑块和按钮 |

镜头可以压低到离水面十几厘米，贴着水面看倒影。面板顶部的小箭头可以收起面板。页面打开后镜头会在初始位置附近缓慢左右摇摆，第一次拖动或缩放后停止。

## 已知问题

- 水波模拟的分辨率约 3.6 厘米，石子激起的第一圈涟漪比较柔和，更细碎的波纹靠风的细波层补足。
- 渲染量较大（倒影 + 折射 + 焦散 + 阴影），在低端手机上会自动降低渲染分辨率来保持流畅。
- 远处的背景树是低面数的风格化树木。
