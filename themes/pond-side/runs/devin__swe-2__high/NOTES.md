# 池塘一隅 · Pond Corner

一个 Three.js 实时 3D 池塘场景，主角是可交互的真实感水面。

## 做了什么

- **水面**：GPU 高度场波动方程模拟（256² 乒乓渲染目标），涟漪向外扩散衰减、相遇叠加、在岸边和栈桥木桩处反射回弹。水面着色结合了镜像相机平面反射（倒影随波纹扭曲）、屏空间折射（水下卵石/锦鲤/木桩随波纹错位扭动）、菲涅尔（平视反光、俯视透水）、按深度的水色吸收（浅处见底、中心幽深）、岸线泡沫与太阳/月亮高光。
- **焦散**：池底着色用波场拉普拉斯估计光线汇聚，浅水处出现随波晃动的光斑，深水衰减。
- **场景**：程序生成的泥岸、卵石、香蒲芦苇丛、枝条垂到水面的垂柳、木栈桥、荷叶与睡莲、水下丝带水草、5 条花纹各异的锦鲤。
- **互动道具**：默认点击水面激起涟漪；石子落水溅起水花、激起大涟漪并沉底（会惊散鱼群）；纸船浮在水面随浪起伏、被涟漪推、被风吹，撞到岸边/荷叶/木桩会弹开，最多同时 8 只；鱼食浮在水面，锦鲤游来啄食，啄食时搅出小涟漪。
- **环境**：风力滑杆（细波密度、芦苇柳树摆幅、漂浮物漂移速度、柳叶飘落频率都随风变化）；雨开关（天色变暗、雨丝、密集小涟漪、倒影模糊）；白天/黄昏/夜晚切换（天色、水色、光照渐变过渡；夜晚水面映月、萤火虫在芦苇间飞并映入水中）。
- 打开页面即有微风吹皱的水面、游动的锦鲤和偶尔飘落水面的柳叶。

## 技术

- Three.js 0.180（本地 vendor，无构建步骤，原生 ES Modules + importmap）
- 所有几何体、贴图（木纹、锦鲤花纹、光斑）均为代码程序化生成，无外部素材
- 渲染管线：波场模拟 → 镜面反射 RT → 折射 RT（裁剪面取水下）→ 主渲染
- 浮物的高度/推力由与 GPU 模拟同步的 CPU 解析波场计算

## 操作

- 鼠标拖动 / 单指滑动：旋转；滚轮 / 双指捏合：缩放（可压低贴近水面看倒影）
- 点击（轻触）水面：按当前选中的道具触发——涟漪 / 扔石子 / 放纸船 / 撒鱼食
- 底部工具栏：道具切换、风力滑杆、雨开关、白天/黄昏/夜晚

## 已知问题

- 折射是屏空间近似，掠射角下水面背后的岸上物体会略有不准确（被菲涅尔反射掩盖，不明显）。
