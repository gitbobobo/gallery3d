# 任务约定

当前目录是一个独立的网页制作任务。任务内容在第一条消息里，本文件只规定工作方式和交付要求。

## 工作方式

- 任务只有那一条消息，过程中不会有人回答问题或确认方案。遇到不确定的地方自己决定，一次做完
- 不要读取或修改当前目录以外的文件（包管理器自己的缓存不算）
- 技术不限，框架、库、构建工具自己选，依赖可以用 pnpm 安装，也可以从 CDN 加载
- 可以自己运行和预览页面来检查效果，启动的服务器用完要关掉

## 交付

- 成品放在 `dist/`，入口是 `dist/index.html`
- `dist/` 会原样复制到一个静态网站的子目录下，用普通静态文件服务器访问，所以：
  - 资源一律用相对路径，不要以 `/` 开头。用 Vite 之类的构建工具时，把 base 设为 `./`
  - 不能依赖后端接口或开发服务器
  - 需要路由时，用 hash 路由或多个 html 文件
- 用了构建工具就要执行构建，`dist/` 里放的是构建产物
- `dist/` 总大小不超过 50MB

## 素材

- 不要使用从网上下载的现成 3D 模型、图片、贴图或 HDRI。几何体和材质用代码生成，或者自己写模型文件
- 第三方库和网络字体可以用

## 展示环境

- 页面会嵌在 iframe 里，以三种尺寸展示：接近全屏、半个屏幕宽、手机竖屏（约 390×844）。页面要铺满可视区域，随尺寸自适应，在手机上能用触摸操作
- 页面打开后，不需要任何操作就要显示主体内容。画廊会在页面加载约 3 秒后自动截图作为封面
- 不要弹出新窗口，不要访问外层页面，也不要让外层页面跳转

## 说明文件

完成后在当前目录用中文写一份 `NOTES.md`，简要说明：

- 做了什么
- 用了哪些技术
- 怎么操作（鼠标、键盘、触摸）
- 已知问题（没有就不写）
